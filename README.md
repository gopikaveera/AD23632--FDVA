## Project Overview

Social media platforms generate data about user activity, engagement, content preferences, and usage habits. Analysing this data can help identify patterns and present useful information through visualizations.

This project uses a social media dataset to explore user demographics, platform preferences, engagement levels, time spent on social media, satisfaction, and productivity-related measures.

The analysis is presented using Python visualizations, a Power BI dashboard, and Tableau visualizations.

## Objectives

- Understand the structure and characteristics of the social media dataset.
- Perform data inspection and exploratory data analysis using Python.
- Visualize platform usage and user behaviour.
- Compare engagement across video categories.
- Examine productivity-loss and satisfaction measures.
- Develop a dashboard using Microsoft Power BI.
- Create visualizations and a dashboard using Tableau.
- Present the findings through clear charts and explanations.

## Dataset Description

The project uses an Excel dataset containing 1,000 records and multiple attributes related to social media usage.

The dataset includes information about:

- User demographics
- Age and gender
- Social media platforms
- Video categories
- Time spent on social media
- Number of sessions
- Engagement values
- Device types
- Reasons for watching videos
- Satisfaction scores
- Self-control and addiction-level scores
- Productivity-loss scores

The dataset is used for descriptive analysis and visualization. Findings are limited to the records provided in the dataset.
